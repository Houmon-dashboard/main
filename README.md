# 訪問歯科 進捗ダッシュボード（テスト版）

訪問歯科の新患〜初診後の事務進捗を、患者番号だけで管理するためのダッシュボードです。

## テスト版について
- HTML / CSS / JavaScript だけで動きます（サーバー不要）。GitHub Pages で公開して試用します。
- データはブラウザの localStorage に保存されます。**端末ごとに別々**で、他の端末とは共有されません。
- **実在の患者情報・氏名は入力しないでください。** 患者番号と氏名の対応は院内で管理します。

## 主な機能
- ダッシュボード：未完了項目一覧（訪問先／患者番号／未完了の項目／1行メモ）、今日・明日・今週・月別の訪問予定、初診前の患者
- 患者一覧：患者番号・訪問先（施設／居宅）・ステータス（プルダウン）
- 患者詳細：初診時チェックリスト（訪問先／医院で区分、プルダウンで進捗管理、入力者と日時を自動記録）、変更履歴
- 訪問予定：予定の追加（「初診」の予定を入れると初診日確定に自動変更）
- 設定：施設名・スタッフ名、データの書き出し／読み込み、サンプルデータ

## 本番化の予定
Xサーバー（サブドメイン）に PHP + MySQL で設置し、ログイン・データ共有に対応する予定です。
